What the Green Card covers

RV64 integer instructions, register conventions, pseudoinstructions, R/I/S/SB/U/UJ encoding fields, opcodes and function bits.

Use your course Green Card while answering. Format questions use the standard RISC-V encoding field layout.

Important limitations

For instruction writing, questions use validated instruction forms; for register tracing, the engine handles the selected arithmetic operations, branches and limited memory operations. Assembly-to-C answers are checked against a taught pattern; equivalent sophisticated programs may still be rejected. This browser-only lab does not compile RISC-V or transmit grades to Blackboard.
