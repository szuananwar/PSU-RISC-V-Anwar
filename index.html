RISC-V Green Card and ABI

Use the instructor-provided Green Card. x10 = a0, x11 = a1, x5 = t0; x0 always reads zero. RV64 register arithmetic and memory operations are used in this course.

Teaching assumptions and limitations

Binary questions use standard 32-bit instructions (not compressed). Assembly may use register aliases. Semantically checked exercises run small input cases in the same subset simulator; not all valid assembly solutions or calling conventions are supported. The instructor should independently check unfamiliar alternatives. Reports are self-reported local browser records, not authenticated grades.

RISC-V Assembly Simulator RV64IM teaching subset

Type or edit an assembly program. Use Run to execute or Step to advance one instruction. Labels and register aliases are supported. Initial registers and memory are zero. Execution stops after at most 2,000 instructions.

Registers x0–x31

Signed 64-bit decimal. x0 remains zero. x10/a0 is often a function return register.

Supported instructions

add, sub, mul, div, rem, addi, and/or/xor, andi/ori/xori, slt/slti, shifts, lb/lbu/lh/lhu/lw/ld, sb/sh/sw/sd, beq/bne/blt/bge/bltu/bgeu, lui, auipc, jal, j, li, mv, nop, ret.

Limitations: no directives, macros, ecalls, full ELF loading, floating-point instructions, pipeline timing or real hardware peripherals. The execution trace and registers are a simplified software model, not real CPU timing measurements.
